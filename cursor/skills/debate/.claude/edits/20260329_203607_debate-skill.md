```powershell

Output panel shows stream, **improvement-plan.md** preview when present, and live Mermaid.

## Invocation from Claude Code

When the user says `/debate`, `/debate <directory>`, or asks to run a code debate:

1. If `<directory>` is not specified, use the current working directory.
2. Run via Bash:
   ```bash
   python "C:/Users/rentk/mihir/agent-skills/cursor/skills/debate/debate.py" "<directory>" --timeout 300
   ```
3. For the persistent Debate Hall server:
   ```bash
   python "C:/Users/rentk/mihir/agent-skills/cursor/skills/debate/hall_server.py" --port 8765
   ```

### Common flags (debate.py)

| Flag | Description |
|------|-------------|
| `--timeout N` | Timeout per agent in seconds (default 300, clamped 30-3600) |
| `--improvement-plan` | Generate SWE/UX/PM improvement roadmap after scoring |
| `--debate-mode sequential\|legacy` | sequential (default): open/challenge/resolve per finding; legacy: parallel bulk vote |
| `--max-findings-debate N` | Cap how many findings get sequential rounds (default: all) |
| `--debate-deadline-seconds N` | Wall-clock cap for debate phase, 0=off (default: 600) |
| `--git-worktrees` | Use isolated git worktrees for parallel agents |
| `--no-ui` | Skip the ephemeral dashboard |
| `--output-dir DIR` | Output directory (default: `<target>/.debate/`) |
| `--hall-url URL` | POST run to a running Debate Hall instead of running locally |

### Key output files (under `<target>/.debate/`)

- `debate-report.md` -- final scored report
- `results.json` -- structured results with scores and findings
- `improvement-plan.md` -- multi-persona roadmap (if `--improvement-plan` or deadline hit)
- `debate_turns.jsonl` -- per-turn debate records
- `debate_graph.mermaid` -- debate flow visualization
